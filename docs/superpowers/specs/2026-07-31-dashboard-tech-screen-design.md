# 知识库看板科技大屏视觉改造设计

## 目标

参考用户提供的深蓝科技数据大屏，将 `index.html` 调整为中央图谱型布局。保留全部现有内容、数据字段、DOM `id`、ECharts 图表和交互逻辑，仅修改视觉样式与模块排版。

## 已确认方向

采用 A「中央图谱型」：

- 深海蓝黑背景，叠加低对比点阵网格和局部蓝色辉光。
- 顶部标题居中，使用科技感框线与青蓝辉光；更新时间和插件状态置于两侧。
- 六个 KPI 横向排列，改为细描边、切角感、局部发光的数据卡片。
- 主体强化视觉层级：核心趋势图占较宽区域，其余分类、状态和列表采用紧凑面板排列。
- 面板统一使用半透明深蓝底、青蓝描边、角标装饰；避免厚重圆角和绿色品牌风格。
- 图表配色统一为 cyan / blue / violet / amber / coral，并降低坐标轴和网格线对比度。

## 范围约束

- 不修改内嵌 `KB_DATA`。
- 不增删任何内容模块。
- 不改变现有 DOM `id`，确保 JS 查询和 ECharts 初始化继续工作。
- 不改变扫描、数据解析和渲染逻辑。
- 不增加新依赖；继续使用现有 ECharts CDN。
- 页面在 1920×1080 最大化窗口中应完整显示，不出现整页纵向滚动；模块内部列表可保留滚动。

## 验收标准

1. 页面所有 KPI、4 个图表、列表、摘要、问题与建议均正常显示。
2. 浏览器控制台无新增 JavaScript 错误。
3. 所有原有 DOM `id` 保持存在且唯一。
4. 1920×1080 视口下整页无纵向滚动。
5. 风格明显接近参考图：深蓝点阵背景、青蓝发光边框、居中科技标题、紧凑数据面板。
6. 移动或窄屏下允许响应式堆叠，内容不溢出视口宽度。
